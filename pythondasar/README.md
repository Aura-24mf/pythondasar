# 🐍 Python Dasar

Repositori dokumentasi, catatan, dan latihan kode pembelajaran **Python Dasar** — mulai dari pengenalan sintaks, struktur data, pemrograman berorientasi objek (OOP), penanganan error dan file, hingga pengelolaan modul dan paket.

---

## 📚 Daftar Materi Pembelajaran

### 1. Dasar & Sintaks Python
* **Hello Python** — Pengenalan awal dan menjalankan program Python pertama
* **Learn Python Basic Structure** — Struktur dasar penulisan kode dan indentasi
* **Learn Python Basic Data Types** — Tipe data dasar (`str`, `int`, `float`, `bool`)
* **Learn Python Variable** — Deklarasi, aturan penamaan, dan penggunaan variabel
* **Learn Python Constants** — Konvensi penulisan nilai konstanta di Python
* **Learn Python Operators** — Operator aritmatika, perbandingan, logika, dan penugasan
* **Learn Python Control Flow** — Percabangan (`if`, `elif`, `else`) dan perulangan (`for`, `while`)
* **Learn Python Functions** — Pembuatan fungsi, parameter, nilai kembalian (`return`), dan *scope*

### 2. Struktur Data
* **Learn Python Lists, Tuples, and Sets** — Koleksi data terurut, tidak dapat diubah (*immutable*), dan unik
* **Learn Python Dictionaries** — Penyimpanan data berbasis pasangan *key-value*

### 3. Pemrograman Berorientasi Objek (OOP)
* **Learn Python Classes and Objects** — Konsep *class*, pembuatan *object*, atribut, dan *method*
* **Learn Python Encapsulation** — Pembatasan akses dan perlindungan data internal objek
* **Learn Python Inheritance** — Pewarisan sifat dan perilaku antar *class*
* **Learn Python Polymorphism** — Penggunaan antarmuka yang sama untuk perilaku berbeda
* **Learn Python Abstraction** — Penyembunyian detail kompleksitas melalui kelas abstrak

### 4. Penanganan Error, File & Organisasi Kode
* **Learn Python Exception Handling** — Menangani kesalahan *runtime* dengan `try`, `except`, `else`, dan `finally`
* **Learn Python File Handling** — Membaca, menulis, dan mengelola file eksternal
* **Learn Python Modules** — Memecah dan mengimpor kode ke dalam modul terpisah
* **Learn Python Packages** — Mengorganisasi kumpulan modul dalam struktur direktori paket

---

## ⚙️ Requirements

* **Python**: Versi `3.8` atau lebih baru (disarankan `3.10+`)
* **Code Editor**: Visual Studio Code (dengan ekstensi resmi *Python*)
* **Version Control**: Git
* **Dependensi Eksternal**: Tidak ada (seluruh latihan menggunakan *standard library* bawaan Python)
